# Вказівки для агентів: video-transcription-uk

- Інструмент має залишатися локальним: не додавайте залежностей, що надсилають аудіо або відео у зовнішні сервіси, без явного запиту користувача.
- Українська мова фіксується кодом `uk` (ISO 639-1); `UA` — код країни, не мови.
- Підтримуйте два формати результату: `markdown` для документації та `plain` для вставки у Notion.
- Залежності змінюйте через `uv add`/`uv remove`; комітьте оновлений `uv.lock` разом із `pyproject.toml` лише після рев’ю.
- Перед передаванням перевіряйте щонайменше `uv run uk-transcribe --help`.
- Не працюйте напряму в `main`: використовуйте гілку `codex/...` і pull request у `main`.
- **Не створюйте комітів або pull request до рев’ю змін користувачем**, якщо він явно не попросив це зробити.
