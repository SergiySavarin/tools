# Транскрипція відео українською

Локальний інструмент для перетворення відео або аудіо на Markdown-документацію з таймкодами, у стилі YouTube:

```md
- **1:07** — Обговорюємо оновлення документації.
- **1:14** — Показую, де розташований файл налаштувань.
```

Розпізнавання виконується локально моделлю Whisper. Відео не надсилається до зовнішнього сервісу. Під час першого запуску модель завантажиться з Hugging Face; надалі вона використовується з локального кешу.

## Підготовка

Інструмент використовує сучасний менеджер Python-проєктів [uv](https://docs.astral.sh/uv/): залежності описані у `pyproject.toml`, а точні перевірені версії — у `uv.lock`. Віртуальне оточення `.venv` створюється та синхронізується автоматично; вручну активувати його не потрібно.

Проєкт зафіксовано на Python 3.13.11 у `.python-version`. `uv` завантажить відповідний Python автоматично, якщо його ще немає. За бажанням цю саму версію можна встановити та обрати через `pyenv`:

На macOS:

```bash
brew install uv ffmpeg
pyenv install 3.13.11
pyenv local 3.13.11
cd "/Users/gru/Documents/ChatGPT/Zona support/video-transcription-uk"
uv sync
```

`pyenv` не є обов’язковим: `uv` також уміє сам завантажувати інтерпретатори. Він корисний, якщо ви керуєте багатьма версіями Python глобально або в інших проєктах.

## Запуск

```bash
cd "/Users/gru/Documents/ChatGPT/Zona support/video-transcription-uk"
uv run uk-transcribe "/шлях/до/відео.mp4"
```

Біля відео буде створено файл `відео.md`. Для явного шляху результату:

```bash
uv run uk-transcribe "/шлях/до/відео.mp4" --output "output/інструкція.md"
```

## Моделі та швидкодія

Типова модель `large-v3` дає найкращий результат для української, але перше завантаження велике й потребує більше пам’яті. Для чернеток або слабшого комп’ютера використовуйте меншу модель:

```bash
uv run uk-transcribe "/шлях/до/відео.mp4" --model medium
uv run uk-transcribe "/шлях/до/відео.mp4" --model small
```

На CPU скрипт типово використовує економний режим `int8`. За наявності NVIDIA CUDA можна використати GPU:

```bash
uv run uk-transcribe "/шлях/до/відео.mp4" --device cuda --compute-type float16
```

## Примітки

- Мова зафіксована як українська (`uk`), переклад не виконується.
- Один рядок Markdown відповідає одному розпізнаному фрагменту та починається з його таймкоду.
- Автоматична транскрипція може помилятися у власних назвах, скороченнях та за поганого звуку — перед публікацією варто швидко вичитати текст.
- Щоб оновити залежність, використовуйте `uv add <пакет>`; не редагуйте `uv.lock` вручну.
