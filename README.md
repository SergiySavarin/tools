# Zona support — інструменти

Колекція невеликих, самодостатніх інструментів для повсякденної роботи та документації.

Кожен інструмент живе у власній папці, має власний README з інструкцією запуску та не повинен залежати від інших інструментів у цьому репозиторії.

## Інструменти

| Інструмент | Призначення |
| --- | --- |
| [video-transcription-uk](./video-transcription-uk/) | Локальна транскрипція відео й аудіо українською у Markdown або простий текст із таймкодами. |

## Принципи репозиторію

- Інструменти мають бути зрозумілими для запуску з чистого середовища.
- Не додавайте у Git секрети, токени, приватні дані, медіафайли або локальні кеші моделей.
- Для Python-інструментів перевага надається `uv`, `pyproject.toml` та `uv.lock`.
- Перед публікацією змін оновлюйте README відповідного інструмента й перевіряйте його основну команду запуску.

## Додавання інструмента

Створіть окрему папку з короткою зрозумілою назвою. Додайте README з призначенням, вимогами, прикладом запуску та описом результату. Локальні налаштування, результати виконання, великі моделі й тимчасові файли мають бути в `.gitignore`.

Правила для агентів зберігаються у [AGENTS.md](./AGENTS.md).
