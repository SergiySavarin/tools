# Вказівки для агентів

## Межі роботи

- Цей репозиторій є публічною колекцією інструментів. Не додавайте секрети, токени, персональні дані, приватні файли, медіа або кеші.
- Працюйте лише в межах запитаного інструмента. Не змінюйте інші підпроєкти без явної потреби.
- Кожен новий інструмент має бути самодостатнім і містити власний README.

## Якість змін

- Дотримуйтеся чинного стеку й стилю конкретного підпроєкту.
- Оновлюйте документацію, коли змінюється спосіб встановлення, запуску або формат результату.
- Виконуйте доступну доречну перевірку перед передаванням результату.

## Git

- Не працюйте напряму в `main` і не намагайтеся обходити захист гілки.
- Для кожного набору змін створюйте окрему гілку з префіксом `codex/` та відкривайте pull request у `main`.
- **Не створюйте комітів або pull request до рев’ю змін користувачем**, якщо він явно не попросив це зробити.
- Перед комітом показуйте склад змін і чекайте явного підтвердження користувача. Після такого підтвердження комітьте лише у робочу гілку, пуште її та відкривайте PR.
